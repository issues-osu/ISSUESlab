## Data Analysis Tutorials

Our lab has developed comprehensive tutorials to help researchers work with complex datasets and analytical tools. These step-by-step guides include code examples, best practices, and real-world applications.

---

### [PostgreSQL Tutorial for Analyzing HMDA Data](/resources/postgresql-hmda-tutorial/)

**From Big Data to Borrowing Bias**

Learn how to download, import, and analyze Home Mortgage Disclosure Act (HMDA) data using PostgreSQL. This tutorial covers:

- Downloading 12M+ mortgage lending records
- Importing pipe-delimited data into PostgreSQL
- Filtering and querying large datasets
- Spatial analysis of lending patterns
- Examining racial disparities in mortgage lending

**Topics**: Mortgage lending discrimination, redlining, spatial analysis, PostgreSQL, big data

[View Tutorial →](/resources/postgresql-hmda-tutorial/)

---

### [CourtListener API Tutorial for Caselaw Analysis](/resources/courtlistener-tutorial/)

**Analyzing Legal Opinions in R**

Learn how to use the Free Law Project's CourtListener API to search, download, and analyze legal opinions. This tutorial includes:

- Searching for cases using the CourtListener API
- Downloading case text and metadata in R
- Working with JSON data structures
- Visualizing case trends over time
- Best practices for API rate limiting

**Topics**: Legal data analysis, API integration, R programming, text analysis, ICWA cases

[View Tutorial →](/resources/courtlistener-tutorial/)
